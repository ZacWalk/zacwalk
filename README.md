Hi, I’m Zac Walker. I’ve been making software since the ’90s.

I wrote [Diffractor](https://diffractor.com) to organize my photos and videos, and I run
[Alpha Galactica](https://alphagalactica.com) to research and follow tech stocks. I also built
[64Ready](https://64ready.com) so you can program a Commodore 64 in your browser. It’s the machine I learned on.

I’m helping to port Microsoft’s infrastructure to Rust. Before that, I worked on the Teams
desktop app and helped bring GCC to Windows on Arm.

You can find more of my projects and the stories behind them at [zacwalk.com](https://zacwalk.com).
